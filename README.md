# Google Apps Script Backend Files

These files contain the backend logic for the Aarambh Naturals application.
You can import these `.gs` files directly into your Google Apps Script project.

## Files Included:
- `main.gs`: Entry point, routing, and standard GET/POST handlers.
- `auth.gs`: Authentication, OTP generation, and user validation.
- `database.gs`: Google Sheets integration and queries.
- `store.gs`: E-commerce operations, cart logic, orders, etc.
- `email.gs`: Email templates and MailApp sending functions.

## Updates:
The `email.gs` template has been updated to reflect the new **Aarambh Naturals** branding and minimalist design without rounded corners.
